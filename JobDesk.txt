===============================================================
1. DESKRIPSI PRODUK
===============================================================

SIMAS Dishub Kota adalah aplikasi berbasis web untuk mengelola surat masuk
secara digital di lingkungan Dinas Perhubungan Kota.

Tujuan sistem:
1. Mencatat surat masuk secara digital.
2. Menyimpan dokumen surat.
3. Mendistribusikan/disposisi surat.
4. Menentukan pegawai atau bagian penerima tugas.
5. Memberikan notifikasi kepada penerima disposisi.
6. Memantau proses tindak lanjut surat.
7. Menyimpan riwayat disposisi.
8. Mencetak lembar disposisi.
9. Membuat laporan surat masuk dalam bentuk PDF.
10. Mengelola user dan bagian.
11. Menyediakan dashboard sesuai role.
12. Mengurangi penggunaan dokumen fisik/paperless.


===============================================================
2. ROLE PENGGUNA
===============================================================

A. ADMIN
---------------------------------------------------------------
Admin memiliki akses paling luas.

Admin dapat:
- Login/logout.
- Melihat dashboard admin.
- Mengelola user.
- Mengelola department/bagian.
- Mengelola jabatan.
- Melihat seluruh surat masuk.
- Menambahkan surat masuk.
- Mengedit surat masuk.
- Menghapus surat masuk.
- Melihat detail surat.
- Membuat disposisi.
- Melihat seluruh assignment/disposisi.
- Memantau status tindak lanjut.
- Mencetak lembar disposisi.
- Membuat laporan PDF.
- Melihat statistik sistem.


B. STAF-LOKET
---------------------------------------------------------------
Staf-Loket bertanggung jawab atas penerimaan dan pencatatan surat.

Staf-Loket dapat:
- Login/logout.
- Melihat dashboard staf.
- Menambahkan surat masuk.
- Mengedit surat masuk.
- Menghapus surat masuk.
- Upload file surat.
- Melihat detail surat.
- Membuat disposisi.
- Memilih pegawai penerima disposisi.
- Memilih department penerima disposisi.
- Melihat status tindak lanjut.
- Mencetak lembar disposisi.
- Membuat laporan PDF.

Staf-Loket tidak dapat:
- Mengelola akun Admin.
- Mengelola akun Karyawan.
- Mengelola Department.


C. KARYAWAN
---------------------------------------------------------------
Karyawan adalah penerima disposisi surat.

Karyawan dapat:
- Login/logout.
- Melihat dashboard pribadi.
- Melihat surat yang ditugaskan.
- Melihat detail surat.
- Membuka file surat.
- Melihat catatan disposisi.
- Mengubah status pekerjaan.
- Memberikan tanggapan/catatan tindak lanjut.
- Melihat riwayat tugas.

Karyawan tidak dapat:
- Membuat surat masuk.
- Menghapus surat.
- Membuat user.
- Mengelola department.
- Membuat disposisi.
